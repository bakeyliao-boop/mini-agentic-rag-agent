# 01 · 首轮取证问题与任务范围

> 状态：收口｜更新日期：2026-09-10
> 结论来源：用户决策，见讨论运行档 H-003、H-004。
> 本文收口的是研究范围，不是实施、实验费用或发布授权。

## 结论（已敲定）

首轮研究自主正文定位：模型自主找到候选文件后，依据问题和工具结果定位相关正文并定向读取，减少无目标的从头分页。

任务以单份政务指南能够回答的问题为主，覆盖三类情况：

1. 问题中包含明确的原文词语。
2. 问题表述与原文措辞不同。
3. 首次读取只有部分证据，需要补充同文档其他区段。

加入另一份未参与策略生成的同类长文档检验迁移。跨文件关系推理、多模态及生产平台改造不纳入首轮。

任务范围不规定必经工具顺序，也不要求必须使用 grep；模型仍自主发现候选、选择工具和参数。只在原指南上改写问题可以做早期检查，不能据此宣称跨文档泛化。

## 现状基线与真实增量

- 当前基线为 1136e44，V1.9 和五个知识工具已实现；六次工具预算、EvidenceRegistry 与引用回源已存在，均为复用基线。
- 自由运行曾多次从头分页；预提供真实 glob/grep 结果的三轮诊断能够按位置读取并停止，但答案与引用仍有不足。来源为原仓库 data/demo-diagnostics/grep-handoff-6a9dafe3ce364f829f0c6748bd2e32cc/REPORT.md，以及当前 PROMPT_VERSIONS.md。
- 预提供定位的诊断改变了初始历史，不能作为自主选工具成功的证据。该脚本保留为诊断对照，不改作正式 Agent 前置步骤。
- 本分支要验证的新增价值是策略候选能否改善可观察的定位行为，并在未见同类长文档中保留收益。
- 当前隔离分支只有一份冻结长指南（4203 行）及五份短教育样例（23～31 行）。新增同类长文档的来源、可用性与脱敏情况需在实验准备前核对，本轮未采集。

## 影响落地单元

- 复用 evaluation/demos/patent_review_comparison_001.json 的既有诊断题面；新任务不覆盖旧评测或伪装成历史结果。
- 复用 evaluation/fixtures/multi_chunk_guide_001/SOURCE.json 与既有冻结语料；新文档和题集的具体组织在评测协议中确定。
- 复用 scripts/diagnose_grep_handoff.py 的诊断和记录经验，但区分 script_prepared 与模型自主决定。
- 可能涉及 rag_core/agentic/prompts.py 的工具决策策略；是否允许及具体编辑边界由 N-02 决定。
- 验收同时观察定位收益、答案与引用质量以及成本；具体数据划分、指标门槛、运行次数和费用由 N-03 决定。
- 本节点不引入数据库、前后端 API 或新的持久化生命周期契约。

## 方案与取舍

- 用户选定自主正文定位优先：直接对应工具决策研究目标；需要自然任务与未见文档验证，效果尚不确定。
- 预算收尾作为未选的首轮主问题保留：它可减少已取证后无结构化结果的失败，但不能直接证明自主定位改善。本结论不表示该问题已解决。
- 用户选定同类政务指南范围并加入未见长文档验证：比只用现有指南增加资料准备与评价成本，换取更有意义的迁移检查；不扩展成跨文件关系推理。

## 验收原则与边界

- 用户问题不得预填内部路径、目标行号、固定操作路线或金标答案点。
- 引用真实、读取范围覆盖和答案充分性分别评价。只读齐而答案或引用不合格时，仅报告定位阶段收益，不认定整体方案通过。
- 不以 grep 调用率更高或工具次数更少单独判断改进；保留失败、回归和额外成本。
- 本节点只确认范围，不规定待讨论的数值门槛、样本数或策略产生方式。
