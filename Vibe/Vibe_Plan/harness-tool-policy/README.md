# Harness工具定位策略规划入口

## 最终目标

**受监督的Harness策略自进化实验**：从真实运行反馈提出受限定位策略候选，做同条件与隔离留出验证，由用户决定是否继承。运行记录、Langfuse Dataset/Experiment及评测都是支撑环节，不以建设日志或评测平台替代目标。先读[ADR-0003](adr/0003-受监督的Harness策略自进化实验.md)。

首轮已确认采用[运行后离线语义评估](adr/0004-首轮采用运行后离线语义评估.md)：mini-agent先独立答完，评估反馈用于后续改策略，不在答题中喂金标。离线不代表本地或免费，具体模型、次数和费用仍未定。

## 后续讨论约定

用户已明确要求采用“黑盒到白盒”模式：从具体场景开始，一次追问一个依赖；不确定时解释例子，再共同推导设计。学习提问不作为再次申请操作授权。完整约定见[ADR-0001](adr/0001-采用黑盒到白盒讨论方式.md)。
